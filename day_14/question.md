## 1. Sort an Array using Merge Sort assending and decending

👉 **Question:**
Given an array, sort it using Merge Sort.

**Example:**

```
Input:  [5, 2, 4, 1, 3]
Output: [1, 2, 3, 4, 5]
```

✔ This is the **standard implementation question**.

---

## 2. Count Inversions in an Array (Very Important 🔥)

👉 **Question:**
Find number of pairs `(i, j)` such that:

```
i < j and arr[i] > arr[j]
```

**Example:**

```
Input:  [2, 4, 1, 3, 5]
Output: 3
```

✔ Trick: Solve using Merge Sort while merging.

---

## 3. Merge Two Sorted Arrays

👉 **Question:**
Given two sorted arrays, merge them into one sorted array.

**Example:**

```
A = [1, 3, 5]
B = [2, 4, 6]

Output: [1, 2, 3, 4, 5, 6]
```

✔ This is the **merge step of merge sort**


## 4. Find Kth Element using Merge Process

👉 **Question:**
Given two sorted arrays, find the **kth smallest element** using merge logic (without merging fully).

**Example:**

```
A = [1, 3, 7]
B = [2, 4, 6]
k = 4
Output: 4
```
