```markdown id="6k2t9p"
## 1. Stack Implementation Using Array

### Problem
Implement a stack with the following operations:
- push(x)
- pop()
- peek()
- isEmpty()
- size()

### Input
```

Operations: push(10), push(20), push(30), peek(), pop(), size()

```

### Output
```

peek() → 30
pop()  → 30
size() → 2
